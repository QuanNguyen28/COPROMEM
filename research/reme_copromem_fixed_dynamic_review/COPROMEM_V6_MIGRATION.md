# V5.3 to v6 migration

V5.3 required an observed sequence to match a frozen exact callable path.
V6 consumes the same public registry and dispatcher telemetry but promotes a
contrastively supported public core with optional alternatives.  Existing v5,
v5.1, v5.2, and v5.3 policies and evidence remain immutable.  V6 state is a
separate `contrastive_v6_schemas` namespace and cannot load prior evaluation
state or guidance.
